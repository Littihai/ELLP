# ELLP — English Learning Language Platform

แพลตฟอร์มเรียนภาษาอังกฤษผ่านวิดีโอแบบ Gamification: ดูเพลง → ทำแบบทดสอบสั้น ๆ → ได้ XP → เลื่อนเลเวล → ทำเควสต์ → ปลดล็อกวิดีโอถัดไป
ออกแบบสำหรับผู้เรียนวัยเด็กและครูผู้ดูแล **เวอร์ชัน 1.0.0** (รุ่นเปิดตัวสาธารณะ รวมงานพัฒนาขั้น 1.0.1 → 1.4.0 ใน changelog) เป็นเดโมแบบกดทดสอบได้ทุกหน้า ใช้ข้อมูลสมมติ ไม่ต้องมีบัญชีหรือเซิร์ฟเวอร์
เหมาะสำหรับส่งให้ผู้สมัครงานหรือทีมพัฒนาดูเป็นโจทย์ตั้งต้น

English version: [README.md](README.md) · บันทึกส่งมอบงานสำหรับนักพัฒนา: [docs/handover.md](docs/handover.md)

## เดโมออนไลน์

https://ellp-littihai.web.app (Firebase Hosting โหมดทดลอง ข้อมูลสมมติเก็บในเบราว์เซอร์ ไม่มี API อยู่เบื้องหลัง)
ประตูผู้เรียน `/login` ประตูผู้ดูแล `/admin/login` รหัสผ่านบัญชีทดลองแสดงบนหน้า

## สำหรับใคร (1.1)

**6 เป้าหมาย (Track)**: เด็กเล็กร้องเพลง, ม.ปลาย/สอบเข้ามหาวิทยาลัย (TGAT, A-Level), TOEIC, IELTS, สอบ ก.พ. และปรับพื้นฐาน โปรแกรมระบุระดับ CEFR
และคะแนนเป้าหมาย ใครก็อ่าน **แคตตาล็อก** และดูบทแรกของทุกโปรแกรมได้ **สมัครเอง** ได้ (หรือให้แอดมินสมัครให้จาก **แชท**) แพ็กเกจ **ฟรี / Pro / Premium**
เปิดบทที่เหลือ โดยใน 1.1 แอดมินเป็นผู้ยืนยันการชำระเงิน ดูเหตุผลที่ [docs/decisions/0005-tracks-plans-signup-chat.md](docs/decisions/0005-tracks-plans-signup-chat.md)

## ความปลอดภัยการเรียน (1.2)

บทเรียน Track สอบเล่นใน **เครื่องเล่นของระบบเอง**: ข้ามไปข้างหน้าไม่ได้ ความเร็วล็อก 1x **คำถามกลางคลิป** ที่ต้องตอบก่อนดูต่อ (จับเวลา หมดเวลาได้ 0)
จำกัดดูซ้ำ เต็มจอ ลายน้ำชื่อผู้เรียน และบันทึกเวลาดูจริง การสลับแท็บ ย่อหน้าต่าง ออกจากเต็มจอ ถูกบันทึกและไต่ **บันได**: เตือน เตือน พักบทเรียน; เปิดอุปกรณ์ที่สอง
เตือน → ตัด session เก่า → ปฏิเสธ ครูเห็นทุกเหตุการณ์และปลดการพักได้ เว็บกันภาพหน้าจอ/บันทึกหน้าจอไม่ได้และหน้าแอดมินบอกไว้ตรง ๆ
ดูเหตุผลที่ [docs/decisions/0006-player-and-learning-integrity.md](docs/decisions/0006-player-and-learning-integrity.md)

## เริ่มตรงไหน เก่งขึ้นด้านใด ผู้ปกครองเห็นอะไร (1.4)

**แบบทดสอบวัดระดับ** ของแต่ละสถาบัน: คำถามติดป้ายทักษะและระดับ CEFR ให้คะแนนแบบขั้นบันได (ผ่านระดับเมื่อถูก 60 % และผ่านทุกระดับ
ก่อนหน้า) ได้ผลเป็นระดับโดยประมาณและโปรแกรมแนะนำไม่เกิน 3 โปรแกรม เปิดให้ผู้เข้าชมทำได้ที่ `/placement` ผลจะติดตามไปกับบัญชีเมื่อสมัคร
ส่วนผู้เรียนบันทึกลงโปรไฟล์ บทเรียนมี **ป้ายทักษะ** (ฟัง พูด อ่าน เขียน ไวยากรณ์ คำศัพท์) รวมเป็นกราฟทักษะในหน้าหลักและโปรไฟล์ โดยมีผล
วัดระดับเป็นจุด "ก่อนเรียน" **บัญชีผู้ปกครอง** เห็นสัปดาห์ของลูกเทียบสัปดาห์ก่อน ทักษะ กิจกรรมล่าสุด และ **รายงานประจำสัปดาห์** เป็นประโยค
สรุปจากตัวเลข ส่งอีเมลผ่านตัวกันโหมดทดสอบ และกดยืนยันบันทึกความยินยอมได้ (decision 0008)

## ชำระเงิน ใบรับรอง ข้อสอบจำลอง (1.3)

ชำระแพ็กเกจด้วย **PromptPay หรือบัตร** ผ่าน payment gateway (ในเดโมเป็นตัวจำลอง; ต่อ Omise / Opn Payments ไว้แล้วสำหรับใช้จริง คีย์อยู่บนเซิร์ฟเวอร์)
หรือ **โอนเงิน** ให้แอดมินยืนยัน ระบบออกเลขใบเสร็จและส่งอีเมล แพ็กเกจมีวันหมดอายุและเตือนล่วงหน้า 7 วัน เรียนครบโปรแกรมได้ **ใบรับรอง** พร้อมรหัสตรวจสอบที่ `/verify`
Track สอบมี **ข้อสอบจำลองจับเวลา** คิดคะแนนตามสเกลของข้อสอบนั้น ดูเหตุผลที่ [docs/decisions/0007-payments-certificates-mock-tests.md](docs/decisions/0007-payments-certificates-mock-tests.md)

## Gamification สรุปสั้น ๆ

ดูวิดีโอถึง **80 %** ได้ XP ของบทเรียน (50–60) แบบทดสอบได้ **10 XP ต่อข้อถูก + โบนัส 20 เมื่อเต็ม** ทำซ้ำได้เฉพาะส่วนที่ดีขึ้น
กิจกรรมแรกของวันขยับ **สตรีค** (+5 XP ต่อวันติดต่อกัน สูงสุด 25) **เลเวล** 1–10 ที่ 0 / 100 / 250 / 500 / 900 / 1400 / 2000 / 2800 / 3800 / 5000 XP
**เควสต์** นับจำนวนวิดีโอ แบบทดสอบที่ผ่าน XP หรือวันสตรีค เป็นรายวัน รายสัปดาห์ หรือตลอดไป ให้ XP และเหรียญตรา
**เงื่อนไขปลดล็อก** ของบทเรียน (จบบท X, ถึงเลเวล N, มี XP ≥ N, ทำเควสต์ Q สำเร็จ, สตรีค N วัน) ต้องผ่านทุกข้อวิดีโอจึงเปิด
เดโมเริ่มที่ **Baby Shark** จบแล้วปลดล็อก *The Wheels on the Bus* ต่อไปเรื่อย ๆ กฎฉบับเต็ม: [docs/gamification.md](docs/gamification.md)

## เงื่อนไขตามอายุ (1.0.1)

**ปีเกิด** ของผู้เรียน (เก็บเฉพาะปี) ให้ช่วงอายุ 3–5 / 6–8 / 9–12 / 13–15 / 16–18 / 18+ โปรแกรมระบุได้ว่าเหมาะกับช่วงไหน บทเรียนตั้งเงื่อนไข `min_age` หรือ
`age_band` ได้ และแต่ละช่วงอายุมีเกณฑ์ผ่านแบบทดสอบ การเห็นกระดานผู้นำ และการไม่ลงโทษเมื่อสตรีคขาดของตัวเองในตั้งค่าของเจ้าของสื่อ
(อ่อนโยนกว่าสำหรับเด็กเล็ก) ครูเปิดทุกช่วงอายุให้เด็กเป็นรายคนได้ บันทึกการรับทราบของผู้ปกครองต่อผู้เรียนเป็นร่องรอยแรกตาม PDPA
ดูเหตุผลที่ [docs/decisions/0004-age-bands.md](docs/decisions/0004-age-bands.md)

## รองรับหลายเจ้าของ (Multi-tenant)

**เจ้าของสื่อ** (โรงเรียน สำนักพิมพ์ ครอบครัว) มีโปรแกรม บทเรียน เควสต์ สมาชิก กล่องข้อความ และการตั้งค่าอีเมลของตนเอง
**ผู้ดูแลระบบ (Super Admin)** เพิ่ม/ลดเจ้าของได้ **เจ้าของ** จัดการผู้ดูแลและผู้เรียน **ผู้ดูแล (ครู)** จัดการเนื้อหาและตอบข้อความ
ผู้เรียนเห็นเฉพาะสังกัดของตนเอง ดูเหตุผลที่ [docs/decisions/0002-multi-tenant-owners.md](docs/decisions/0002-multi-tenant-owners.md)

## เทคโนโลยี

- **Frontend**: React 19, TypeScript, Vite, react-router; ใช้ design tokens และแนวทาง UI จากโปรเจกต์ TMCL-PR
  (ธีมสว่าง/มืด พจนานุกรมไทย/อังกฤษ ไอคอน Octicons ไม่ฝังข้อความในโค้ด)
- **Backend**: C# / ASP.NET Core 9 Web API, Firebase Admin SDK (ตรวจ ID token, Firestore), MailKit (SMTP พร้อมโหมดทดสอบ), xUnit
  กฎทั้งหมดเป็น static class ล้วนและมี test
- **Firebase**: Authentication (อีเมล/รหัสผ่าน), Firestore (ข้อมูล ผ่าน service account ของ API), Hosting (ทางเลือก)
- **โหมดทดลอง**: frontend ทำงานบน store ในหน่วยความจำที่เก็บใน localStorage; API มี store ในหน่วยความจำและโหมด header `X-Demo-User`
  ดูเหตุผลที่ [docs/decisions/0003-demo-mode.md](docs/decisions/0003-demo-mode.md)

## ข้อจำกัดของ 1.0.0 (ตามจริง)

- ความคืบหน้าการดูในเดโมใช้ตัวจับเวลาและปุ่ม "ดูจบแล้ว (จำลอง)"; โหมดจริงควรใช้ตำแหน่งจริงจาก YouTube IFrame API
- ข้อมูลตั้งต้นไม่มีวิดีโอ: ทุกบทเรียนแสดง "ยังไม่มีวิดีโอ" จนกว่าสถาบันจะใส่ YouTube id หรือ URL ไฟล์/HLS ของตนเองใน Admin › บทเรียน ภายใต้ลิขสิทธิ์ของตน
  ปุ่ม "ทำเครื่องหมายว่าดูแล้ว" ของเดโมทำให้กดทดสอบทุกขั้นตอนได้โดยไม่ต้องมีวิดีโอ
- Firestore store และการเข้าสู่ระบบผ่าน Firebase เขียนไว้แล้วแต่ยังไม่ได้ทดสอบกับโปรเจกต์จริงในเวอร์ชันนี้
- อีเมลใช้ตัวส่งแบบบันทึก log อย่างเดียวจนกว่าจะตั้งค่า SMTP; โหมดทดสอบเปิดไว้เป็นค่าเริ่มต้น
- ยังไม่มี UI test อัตโนมัติ; backend มี test กฎและเอนจิน 109 รายการ
- รายงานประจำสัปดาห์ถึงผู้ปกครองสร้างจากตัวเลขตามกฎ และส่งด้วยปุ่มกด (งานตั้งเวลาอยู่ใน roadmap)
- Omise gateway เขียนไว้แล้วแต่ยังไม่ได้ทดสอบกับบัญชีจริง; gateway จำลองไม่ตัดเงินจริง
- คะแนน TOEIC/IELTS ในข้อสอบจำลองเป็นค่าประมาณสำหรับฝึก ไม่ใช่การเทียบอย่างเป็นทางการ
- เครื่องเล่นของแพลตฟอร์มและกติกาความปลอดภัย (ล็อกการเลื่อน คำถามกลางคลิป บันไดเตือน) จะเห็นได้เมื่อบทเรียนมี URL วิดีโอแล้ว บทเรียนสอบในข้อมูลตั้งต้นเตรียม checkpoint ไว้รอ
